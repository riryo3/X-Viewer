# X-Viewer

X（旧 Twitter）を見るためだけの、Mac 用の簡易ブラウザです。

中身は Mac 標準の WebView（WKWebView）ひとつだけ。開くのは X だけで、投稿に出てくる外のサイトへのリンクは普段のブラウザで開きます。アドレスバーはありません。

## 特徴

- **縁ボタン**: 画面の左端をクリック = 戻る / 右端 = 進む / 上端の左半分 = おすすめ / 上端の右半分 = フォロー中 / 下端 = 自分のプロフィール。大きな的を狙う感覚で操作できます
- **プロフィール設定**: 初回起動時にプロフィールの URL か @ユーザー名 を聞きます。下端ボタンでいつでも自分のプロフィールへ飛べます（あとから表示メニューで変更可）
- **ピン留め（フロート）**: 上端の右すみの小さなボタン（または ⌘T）で、最前面に固定できます。状態は次回起動時にも復元されます
- **ウインドウスナップ**: ドラッグすると、画面の隅や他のアプリのウインドウの縁に吸着します
- **色はシステムに従う**: ライト／ダークの切り替えに追随します（X の中身の色は X 側の表示設定次第）
- ログイン状態・ウインドウの大きさと位置は自動で保持されます

## 使い方（ビルド）

Xcode（または開発者ツール）が入っている Mac で、ターミナルから:

```sh
sh build.sh
```

同じフォルダに `X-Viewer.app` ができます。ダブルクリックで起動、気に入ったら「アプリケーション」フォルダへどうぞ。

ソースを直したあとも、同じコマンドで作り直せます。

## 操作

| 操作 | 意味 |
|---|---|
| 左端クリック | 戻る |
| 右端クリック | 進む |
| 上端の左半分クリック | おすすめ |
| 上端の右半分クリック | フォロー中 |
| 下端クリック | 自分のプロフィール |
| 上端右すみのピンボタン / ⌘T | 最前面に固定（フロート） |
| ⌘R | 再読み込み |
| ⌘[ / ⌘] | 戻る / 進む |
| ⇧⌘H | ホーム |

縁の上にマウスがあるときでも、ホイールスクロールはそのままページに効きます。

## 中身

- `main.swift` — アプリ本体（Swift + WKWebView、1ファイル）
- `Info.plist` — アプリの情報
- `build.sh` — .app にまとめるスクリプト
